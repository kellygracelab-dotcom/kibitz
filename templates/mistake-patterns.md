# Mistake patterns

> Filled in from engine output only, never from a feeling about the game.
> One bad move in one game is noise. A pattern needs **three occurrences in
> three different games** before it goes in the confirmed section.

## Confirmed patterns

None yet.

Record format:

```
### <short name> - confirmed <date>

- Games: <file names>
- What happens: <the mechanism, in one or two sentences>
- Instances:

  | Game | Played | Better | Loss |
  |---|---|---|---|
  |  |  |  |  |

- Trigger: <the board situation that sets it off>
- Evidence from the clock: <time spent, if the PGN has clock data>
- Countermeasure: <one concrete check, small enough to actually do>
- Status: active | closing (N of 3 clean games) | closed <date>
```

A pattern is closed only after it fails to appear in three consecutive games.
If it reappears, the count resets to zero. Being able to explain a mistake is
not the same as having stopped making it.
